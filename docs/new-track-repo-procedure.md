# New-track procedure

Track creation and provisioning are organizer operations. They are not part of
the participant workflow.

Participants must not change track identity, fixture pins, trusted workflows,
or vendor provenance. The allowed submission surface is exactly
`benchmark.json` `editablePaths`.

For this track, use:

- [README.md](../README.md) for setup and submission;
- [participant-contract.md](participant-contract.md) for rules;
- `benchmark.json` for editable paths and commands;
- `fixtures/nemotron3_5_30b_a3b_mlx_v1_track.json` for current pins and scoring
  values.
